## 起因

最近半年，LLM 圈子里有两件事让我越来越不舒服。

第一件：**小模型狂热症**。Phi、Gemma、Qwen 的 1.5B/4B/7B 版本出来一个炸一个，每个都号称"以小博大""在某些 benchmark 上超越 GPT-4"。然后你兴冲冲去试——对话确实流畅，写代码也还行，但一旦让它上网查资料、交叉验证、从噪音里捞出真相，它就原形毕露了。被钓鱼网页骗、被 SEO 垃圾带偏、把广告当权威信源……这些小模型在*信息收集*任务上的表现，用"惨不忍睹"来形容不算夸张。

第二件：**越来越抽象的"评测比较"**。"DeepSeek-v4-Flash 已经全面碾压 Claude-5-Fable 了"——我看到这种帖子的时候，第一反应是：你拿什么测的？MMLU？GSM8K？还是某个 prompt 是"请用鲁迅的文风写一段小红书文案"的 vibe check？我不是说这些评测没有价值，但它们在**真实世界的信息收集场景**中能说明多少问题，我打个巨大的问号。

反过来，另一种声音也很刺耳："GLM-5.3 就是纯刷榜，真实能力一塌糊涂""XX 模型除了考试啥都不会"。我同样难以苟同。因为——你拿什么测的？

## 这个仓库在做什么

这是一个**模拟真实信息收集任务的 benchmark**。它和编程无关，和数学竞赛无关，和"请用 JSON 格式输出"的 prompt engineering 也无关。

它只做一件事：

> 给你几个工具（搜索、读网页、查天气），问你一个问题。互联网上有正确答案，也有大量看起来像正确答案的陷阱。请自己判断。

具体来说，这道题是：

> **"克里斯瓦尔的天气是多少°E？"**

你需要：
1. 搜索"克里斯瓦尔"在哪里
2. 发现它属于一个叫"泽科霍纳斯"的国家
3. 调用天气工具查泽科霍纳斯的气温（得到 15.23°C）
4. 搜索"°E"（尔式度）的换算公式
5. 在多个网页中甄别**哪个是真正的公式，哪个是陷阱**
6. 算出正确答案：**31.937°E**

听起来不难？对，人类做这道题大概需要 30 秒。

但很多 LLM 会算出 **30.46°E**——因为它们在某个网页里看到了"°E = °C × 2"，然后就信了。即使另一个网页用 `<span style="color:white">` 把这句话藏在白色背景里，即使另一个网页用 `opacity: 0` 把一个覆盖层里的错误答案藏了起来——模型读网页的时候，它是"看"不到这些 CSS 的，它看到的是 HTML 源码。在源码里，这些陷阱和正确答案**同样显眼**。

这就是现实世界的信息收集：SEO 垃圾、钓鱼网站、广告软文、过时的论坛帖子、以及各种阴间 CSS 花招——它们都在和真正的权威信源争夺模型的注意力。

## 关于评测：为什么这里不给出排名

**同一个模型，在不同的量化版本、不同的推理提供商上，表现可能天差地别。**

一个 `Q4_K_M` 量化的模型和一个 `Q8_0` 的模型，在信息甄别任务上的表现可能差了十万八千里。同理，同一个模型在官方 API 上和某个第三方代理上的表现也可能不同。

所以我不会在这里维护一个"XX 模型第 X 名"的排行榜。你拿着代码自己去测，结果是什么就是什么。但有一个规律我观察到了：

> **参数量越大、激活量越大的模型，幻觉越少，被陷阱带偏的概率越低。**

这不是什么深刻的洞见，但它值得被反复说：在当前阶段，大不一定就是好，但是大更有可能就是好。

---

## 为什么这件事很重要

如果 LLM 在帮你分析财报，它把某个网页里隐藏的虚假营收数据当成了真实数据，结果可能是灾难性的。

如果 LLM 在帮你检索药物相互作用，它把某个 SEO 优化过的伪科普网站当成了权威信源，结果可能是致命的。

**越是金融和医疗领域，幻觉和不实信息就越是致命。** 而这些领域恰好是信息检索需求最密集、信源质量最参差不齐的领域。你不能指望用户自己去 cross-check——如果用户有能力 cross-check，他为什么要用你？

## 关于我的私榜

这个仓库的测试题与我的 私榜的正式测试集是正交的，并且这里只有一道题，它不是用来排名的，是用来展示理念的：

> **一个真正有用的 benchmark，不应该是"模型在已知数据集上的分数"，而应该是"模型在真实、嘈杂、充满陷阱的信息环境中，能不能找到正确答案"。**

## 快速开始

```bash
# 安装依赖
pip install openai

# 设置你的模型
export MODEL_API_BASE="https://your-api-endpoint/v1"
export MODEL_API_KEY="sk-your-key"
export MODEL_NAME="your-model-name"

# 开跑
python eval.py
```

模型会经历搜索→读网页→查天气→计算的过程，最终输出一个数字。如果输出 `31.937`（或 `31.94`），恭喜，你的模型没有被钓鱼。

如果输出 `30.46`……你的模型被带偏了。它可能在哪一页的白色文字里看到了"×2"，然后信了。

## 最后

我不反对小模型，也不反对排行榜。但我反对**把 benchmark 当成模型能力的全部**，更反对**在不知道测了什么的情况下拿 benchmark 分数互相攻击**。

一道题，一个真实的信息收集场景，五个网页，若干陷阱。

你的模型能算对吗？
